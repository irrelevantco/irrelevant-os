Portable Windows x64 personal preview **v0.2.2**. Extract the complete ZIP, close the old app and open **iRRELEVANT OS.exe from the new folder**. Your existing local Docker database/account stays in place; no data or credentials are bundled.

- **Free preparation:** explicit **Resume free preparation** preserves your limits and sender identity. Research plans use built-in rules without model fees or API keys. Outreach still needs an approved sourced review; follow-ups require actual outbound contact history. Everything remains draft-only.
- **Free business discovery:** OpenStreetMap via Private.coffee, without an API key. Fixed municipality/trade filters, up to 10 candidates/request, three requests/day with a one-minute cooldown. Optional Explee remains separate. Coverage and provider uptime vary; empty results and connection failures are reported without invented leads or paid fallback. Review candidates through Imports before committing.
- **XLSX/CSV converter:** choose worksheet/header row, map fields, validate and preview, then approve CSV/XLSX/JSON export. Templates: prospects, employee directories, payroll summaries, applicants/resume links, shifts, work orders and custom columns. Non-prospect contents remain in the app window; only explicitly approved business records can enter the CRM import flow. This is not payroll processing, resume-document parsing or an ADP/Kronos integration.
- **Actual Windows icon:** neon iR embedded in the executable and applied to the app window and PWA assets. Unpin an old Atom shortcut and pin the new executable if Windows retains the old path/icon. Sidebar and Workspace → About identify v0.2.2.

**First launch after updating:** leave the existing Supabase containers running, then choose **Workspace → Update local database…**, confirm and reload. The updater applies missing additive migrations without resetting records. For a new app profile, import the connection from your existing `.env.local` and use the same account email. Then open Agent control → Resume free preparation. A queued job still needs **Run next queued job** while you are signed in.

Repository verification covers type/lint/production build, 105 unit tests, 132 real local database/repair assertions, six desktop/mobile browser workflows and fresh migrations with RLS on all 15 tables. Browser checks exercise XLSX → reviewed CRM import, text-ID preservation, downloads and no employee-data POST. Windows packaging verifies embedded icon bytes and native startup before publication. Real local sign-in, Agent control, XLSX parsing and native updater are exercised separately in the Linux desktop package. The optional provider connectivity result is retained in the Windows workflow artifact; public service availability is not guaranteed.
