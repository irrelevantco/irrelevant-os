Portable Windows x64 personal preview **v0.3.0**. Close the old program, extract the complete ZIP, and launch **iRRELEVANT OS.exe from the new folder**. Check v0.3.0 in the sidebar or Workspace → About. Keep your existing Docker/Supabase containers running. Choose **Workspace → Update local database…**, confirm and reload; existing accounts, prospects, notes and drafts are preserved.

Implemented in this release:

- **Opt-in hourly acquisition targets:** Connections → enable weekdays 7 a.m.–3 p.m. Eastern, choose categories/city/state. Target up to five new map candidates per selected category/hour; seven categories means at most 56 searches/day, within a 100-job ceiling. Requests are staggered, idempotent and not automatically retried. Completed candidates stage import previews; businesses still require your import approval. Coverage can produce fewer/no new candidates.
- **Native desktop runner:** checks once per minute using your signed-in owner session. The app must remain open, PC awake and backend available. Missed hours are skipped. This is not an always-on hosted scheduler.
- **Agreed appointments:** Calls & meetings records actual agreed dates/times and optional estimates. SQL enforces future weekday appointments fully inside 7 a.m.–3 p.m. Eastern and prevents local overlaps.
- **Live dashboard:** Open opportunity value counts each open lead estimate once when there is a non-cancelled agreed appointment. Values refresh every ten seconds while visible; these remain estimates, not contracts or revenue.
- **Google capability code:** PKCE/state-protected OAuth, owner/runtime-bound encrypted credentials, exact-message Gmail approval with a five-attempt daily limit, actual contact logging on confirmed sends, and deterministic Calendar event IDs with availability checks. Guest invitations require a separate checkbox. These adapters require your own Google OAuth client and consent; they are not connected or activated by downloading the app.
- **Clear phone status:** local installations now explicitly say phone hosting is not connected. A localhost address cannot become a PC-independent phone app through Add to Home Screen.

Google Cloud sign-in was not completed, so no real Google project/client was created. Live Gmail delivery and Calendar writes were not exercised; automated provider tests use synthetic responses. No emails or invitations were sent. Reply/opt-out synchronization is not implemented; log replies/opt-outs manually before further outreach. An uncertain delivery stays blocked from automatic retry; an in-app resolution workflow is not implemented. Contracts, payments, autonomous meeting negotiation and phone-call placement are not included.

Google setup can be imported through **Workspace → Import Google OAuth setup…** using an official **Desktop app** OAuth client JSON. It is encrypted with Windows OS credentials; plaintext fallback is refused. Complete consent through **Workspace → Open Google connection in browser…**, signing into the CRM there. For a hosted app, configure a Web OAuth client and server encryption key on the host. No client secret or account password is included in this ZIP.
