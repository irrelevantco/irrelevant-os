This personal update adds the regional acquisition engine and removes the pipeline's 500-loaded-lead cutoff.

**Update safely:** Keep Docker running. Choose **Workspace → Check for app updates…**, download, install/restart, then **Workspace → Update local database…** once and reload. The additive migration retains existing organizations, leads, notes, research and encrypted connection records. Do not reset your database. This does not transfer data from another PC.

**Acquisition engine:** Configure an active lead goal (default 1,000), PA/OH/NY territories and 13 service/food/beauty categories. Free map discovery rotates bounded searches and either stages previews or, only with your separate opt-in, imports unverified Discovered prospects. CSV capacity increases to 2,000 rows / 1 MB, preserving source URL/timestamp and duplicate protection. Listings are not verified weaknesses, budgets or guaranteed email contacts.

**Research:** A/B/C priority public-web checks capture up to three pages under robots, DNS/address, timeout and size restrictions. Free rules are the default; installed local Ollama models are optional. OpenAI requires an explicit model, server credential, configured prices/cost cap and owner consent; no paid fallback or automatic model retry exists. Completed proposals remain unverified until manually reviewed. Public mailto candidates can be reviewed and explicitly copied without overwriting saved contacts.

**Optional automatic outreach:** Installation does not turn sending on. Renew Gmail permission from **Connections → Connect Gmail replies for the engine** to enable reply reading. Then review the engine's full templates, actual sender/postal identity, sample messages and limits before approving a seven-day campaign. Default allowance: 25 messages per rolling 24 hours, 100 attempts per campaign. All three review pillars must be manually verified/source-backed and owner-approved. Existing exact-message manual approval remains available.

Optional bounded follow-ups stop after any genuine reply. Authenticated positive replies may receive a standard acknowledgement or two checked meeting options. Only an explicit authenticated Option 1/2 reply to an actually sent offer may create an agreed appointment/invitation, Monday–Friday 7 a.m.–3 p.m. Eastern, after another availability check. Ambiguous replies need manual handling. No price negotiation, signed agreement, payment or Won status is automated. Unknown deliveries are held for manual Gmail reconciliation, never automatically retried.

Keep the app open, PC awake, Docker running and owner signed in. This is a local runner, not an always-on hosted worker. The cumulative send goal is distinct from Gmail's account allowance, which also includes ordinary Gmail usage. Google can restrict delivery earlier. Pause, opt-outs, changed evidence/identity and quotas are enforced at claim time.

The pipeline now searches the full organization and uses 12-card server pages per stage. Overview adds a private count report for account/workspace/backend, active leads, Trash and import results. The reported 387 → 311 difference remains unconfirmed on the user's Windows database; this release does not claim to recover missing records automatically.

Verification includes >1,000-record pipeline/import tests, owner/tenant isolation, campaign gates/quotas, idempotent deliveries, reply/appointment flows, existing Trash/upgrade regression and desktop/mobile browser checks. No real emails or invitations were sent while developing this update. No billing or hosted deployment is enabled. The Windows package remains an unsigned personal preview.
